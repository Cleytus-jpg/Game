# Custom Tile Images

Place your custom PNG images in this folder to customize the appearance of tiles.

## Required Files

- `tile-2.png` - Image for tile value 2
- `tile-4.png` - Image for tile value 4
- `tile-8.png` - Image for tile value 8
- `tile-16.png` - Image for tile value 16
- `tile-32.png` - Image for tile value 32
- `tile-64.png` - Image for tile value 64
- `tile-128.png` - Image for tile value 128
- `tile-256.png` - Image for tile value 256
- `tile-512.png` - Image for tile value 512
- `tile-1024.png` - Image for tile value 1024
- `tile-2048.png` - Image for tile value 2048

## Image Specifications

- Format: PNG (with transparency support)
- Recommended size: 100x100 pixels or larger
- The images will be automatically scaled to fit the tile size
- Use transparent backgrounds for better visual effect

## Tips

- Keep images simple and clear
- Use high contrast for better visibility
- Consider using emojis, icons, or themed graphics
- Test images at different sizes to ensure they look good

If no custom images are provided, the game will use the default colored tiles with numbers.
